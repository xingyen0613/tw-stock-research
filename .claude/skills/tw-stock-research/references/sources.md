## 程序化取得（優先於搜尋）

**能用 API 拿到的東西，不要用 web search。** 搜尋回來的財務數字是二手轉述、要自己核對、而且常常是「近四季」與「單季」混用。API 拿到的是結構化原始值。

### 量化財務 → FinMind API

```bash
python3 .claude/skills/tw-stock-research/scripts/fetch_financials.py {代號} --out financials.json
```

一次拿齊：逐季損益（營收／毛利／營益／稅前／稅後／EPS）、資產負債、現金流、月營收與逐月 YoY，並算好毛利率、營益率、淨利率、流動比、速動比、負債比、單季 ROE、每股淨值、QoQ、YoY。輸出約 12KB。

已驗證的事實（2026-08 實測 3533）：

- **免 token 可用**。免費層 600 req/hr，本腳本一檔只用 5 個 request。環境若有 `$FINMIND_TOKEN` 會自動帶上。
- **損益表與現金流是單季值，不是累計值**，不需要還原。資產負債表是期末餘額。
- 資料源是公開資訊觀測站財報。標 L1 時要在 MOPS 對得上；對不上就標 L2。腳本輸出的 `meta.mops_url` 是該公司財報查詢頁，可直接當引用連結。

### 法說會簡報 → MOPS 查清單(瀏覽器) + curl 抓檔

**2026-09-12 實測更新**：舊版寫「查清單走 API、不要用瀏覽器」已經過時。MOPS 前端改版後，`t100sb02_1` 這類查詢 API 會被 WAF 擋下（純 curl 回「因為安全性考量」錯誤頁；加上瀏覽器常見的 User-Agent/Referer/Origin header 能過 WAF 第一層，但端點仍要求 SPA 載入後才有的 session 狀態，最終還是 404）。目前**查「有哪些場次」這一步只能用瀏覽器工具**：

1. 開 `https://mops.twse.com.tw/mops/#/web/t100sb02_1`，填公司代號與民國年、點查詢
2. 用 `read_network_requests` 找 `POST /mops/api/redirectToOld` 這筆請求，其回應 body 是 `{"result":{"url":"https://mopsov.twse.com.tw/mops/web/ajax_t100sb02_1?parameters=..."}}`
3. `navigate` 到這個帶簽名參數的網址，`get_page_text` 就能拿到完整結果表格（含每場日期、地點、簡報檔名）

**一次查完該公司過去兩個民國年度的完整清單，不要只查最近一年或假設「一季一場」。** 高力(8996) 2025-2026 兩年實際開了 15 場券商投資人論壇（同一季可能 2-3 場），A-1 若只查一年範圍或半途停止分頁，容易只抓到 4-5 場就以為抓完——實際上要把完整清單抓回來，依日期排序取最新 4 場，而不是抓到幾場算幾場。

**檔案下載本身仍是純 API，維持原做法**：簡報 PDF 網址格式 `https://mopsov.twse.com.tw/nas/STR/{代號}{西元日期}M{序號}.pdf`（少數是 `.pptx`），拿到查詢結果表格裡的確切檔名後，直接 `curl` 下載即可，不需要瀏覽器。

**拿到 PDF 一律先 `pdftotext -layout`**，細節見 SKILL.md 的「PDF 處理鐵則」。實測法說會簡報的業務別營收占比表用 `-layout` 能完整保留欄位對齊（各業務別、各年度占比、市場趨勢、下年度展望全在），單頁 980 token；同一頁轉成 PNG 讀進 context 是 145,000 token。若拿到的是 `.pptx`（偶爾發生），不要轉圖，直接 `unzip` 解壓後對 `ppt/slides/slide*.xml` 跑正則 `<a:t>(.*?)</a:t>` 抓文字節點即可，同樣是純文字操作，不需要 LibreOffice 或任何轉檔工具。

### 業務別營收拆解 → 財報附注「部門資訊」（比法說會簡報更權威）

**2026-09-12 新增**：法說會簡報幾乎不會有業務別營收金額或占比（實測高力 5 場簡報全部沒有），但這不代表公司完全沒有官方拆解——**合併財務報告附注「部門資訊」（IFRS 8 規定揭露）才是真正權威的來源**，FinMind 的財務資料只含損益表科目、不含附注，法說會簡報也不含，所以 A-1／A-2 兩邊都碰不到，必須另外查。

做法：MOPS 查「財務報告書」（`t57sb01_q1`），取得該公司最新年報與最新一季合併財報 PDF 的檔名，用 `doc.twse.com.tw` 兩段式下載（純 curl，不需要瀏覽器）：

```bash
# 第一步：POST 表單取得帶時間戳記的實際檔案網址
curl -sL -d "step=9&kind=A&co_id={代號}&filename={檔名}.pdf" \
  "https://doc.twse.com.tw/server-java/t57sb01" > resp.html
# resp.html 內文會有一行 <a href='/pdf/{檔名}_{時間戳}.pdf'>
url=$(grep -oE "/pdf/[^']+\.pdf" resp.html | head -1)
# 第二步：直接抓檔
curl -sL -o out.pdf "https://doc.twse.com.tw${url}"
```

`filename` 從財報書查詢頁的表格取得（例如 `202504_8996_AI1.pdf` 代表 114 年第 4 季／全年合併財報）。拿到 PDF 後 `pdftotext -layout`，`grep -n "部門資訊\|部門別"` 定位附注段落——年報與每季合併財報通常都有這個附注（IAS 34 期中報告的簡化揭露規定下，部分公司可能只在年報揭露，實測高力是季季都有）。附注內容包含：各部門營收、部門損益（部門利益率）、可辨認資產負債、地區別營收、主要客戶集中度（依 10% 門檻匿名揭露）。**這組數字才是本報告「業務別營收拆解」章節該優先採用的來源，投資人簡報的質性業務分類只能當輔助説明。**

### 本益比河流圖（圖 5）→ FinMind API

```bash
python3 .claude/skills/tw-stock-research/scripts/fetch_pe_band.py {代號} --years 5 --out pe_band.json
```

自己去抓 `TaiwanStockPrice`、`TaiwanStockFinancialStatements`、`TaiwanStockPER`，算出月均價、
近四季 EPS、本益比與各區間色帶。輸出約 5KB。已驗證的事實（2026-08 實測 7 檔）：

- **`TaiwanStockPER` 是證交所每日公布的官方本益比**（上市、上櫃都有，回溯 5 年以上）。
  它的分母就是「最近四季 EPS 總和」——實測台達電 2026-08-25 收盤 1710 ÷ 31.42 = 54.42，
  與證交所公布值一字不差。腳本用它反推**市場當下採用的 EPS 口徑**，據此定出每一季的換檔日
- **換檔日是各公司財報實際公布日，不是法定申報期限**。實測台達電 2026Q2 在 07-29 換、
  嘉澤在 08-14 換，差 16 天。用法定期限（5/15、8/14、11/14、3/31）一律猜，
  會讓換檔前幾週的本益比全部算錯
- **`PER` 欄位為 0 代表當時近四季 EPS 為負**，不是缺值。虧損期間拿不到換檔日，
  腳本會退回法定期限推算
- 覆蓋率不足或本益比跨度過大時腳本會給 `skip_reason`，那時**這張圖就不要畫**

### 股價、法人買賣超、融資券

同樣走 FinMind（`TaiwanStockPrice`、`TaiwanStockPER`、`TaiwanStockInstitutionalInvestorsBuySell`、`TaiwanStockMarginPurchaseShortSale`），用法見 `~/.claude/commands/finmind.md`。

### 什麼**不能**程序化取得

這三類只能靠 web search，這是本報告 web search 預算該花的地方：

1. **法說會 Q&A** — 簡報 PDF 幾乎不含，只有逐字稿、影音摘要、現場報導有
2. **法人財測與目標價** — 外資報告只能透過媒體轉述
3. **產業分析與空方論述** — 研調機構觀點、社群爭議點

## L1 官方來源

### 公開資訊觀測站（MOPS）
台股所有官方資料的源頭。`https://mops.twse.com.tw`

要拿的東西：
- **法人說明會一覽表** — 每場法說會的日期、地點、中英文簡報 PDF 連結、影音連結
- **法說會簡報 PDF** — 網址格式通常是 `https://mopsov.twse.com.tw/nas/STR/{代號}{日期}M{序號}.pdf`。這是業務別營收占比最權威的來源
- **財務報表** — 合併損益表、資產負債表、現金流量表
- **重大訊息** — 董事會決議、除權息、轉投資、產能擴充
- **月營收公告** — 每月 10 日前公布

### 公司投資人關係網站
有些公司會放法說會逐字稿或影音，比 MOPS 完整。從公司官網找「投資人關係」。

### 法說會影音
YouTube 上常有法說會全程錄影。若有逐字稿，Q&A 環節通常只能從這裡拿到——**簡報 PDF 幾乎不含 Q&A**。

### 好用的聚合站（資料源仍是 MOPS，但比較好翻）
- 財報狗 `statementdog.com/analysis/{代號}/` — 逐季損益、EPS、利潤比率，適合快速拿 4 季序列
- Goodinfo `goodinfo.tw` — 最完整的個股概況、新聞公告時間軸
- 玩股網 `wantgoo.com/stock/{代號}/financial-statements/` — 逐季財務報表

這些站的數字**來源是 L1，但呈現是二手**。若能對到 MOPS 原始檔就標 L1，對不到就標 L2。

## L2 法人／研調

- **MoneyDJ** `moneydj.com` — 台灣最常轉述券商觀點的媒體，法人預估的主要來源
- **DIGITIMES** — 供應鏈與產業趨勢
- **TrendForce** — 記憶體、面板、半導體、AI 伺服器產業數據
- **Anue 鉅亨** — 外資報告轉述、目標價變動
- **經濟日報／工商時報** — 法說會現場報導，Q&A 內容常常只有這裡有

外資報告（大和、摩根士丹利、高盛、瑞銀、花旗、美銀）通常只能透過媒體轉述取得。轉述時務必寫明：**哪一家、什麼時間、目標價多少、基於什麼假設**。只寫「法人估 EPS 95 元」而不說是誰、什麼時候估的，這個數字沒有價值。

## L3 媒體／社群

- CMoney、理財周刊、方格子（vocus）、YouTube 財經頻道
- PTT Stock 板、股市爆料同學會、Facebook 社團

L3 的價值不在數字，在**觀點與爭議點**。用它來找：
- 市場在吵什麼
- 空方的論述是什麼
- 有沒有人質疑官方財測

L3 提到的數字若無法回溯到 L1/L2，標註「未經查證的單一來源」，或直接不用。

**特別注意**：很多 L3 內容是 AI 自動生成的整理稿（方格子、CMoney 的部分文章會標「含 AI 應用內容」）。這類內容可以拿來當線索，但數字一定要回頭對 L1。

## 搜尋策略

查詢字串保持短（3–6 字），先廣後窄：

| 目的 | 查詢範例 |
|---|---|
| 找法說會 | `{代號} 法說會 {年份}` |
| 找法說會逐字／Q&A | `{公司名} 法說會 記者會 問答` |
| 找財報 | `{代號} {年度}Q{季} 財報 EPS` |
| 找法人財測 | `{代號} 目標價 法人 EPS 預估` |
| 找產業分析 | `{focus} 產業 分析 {年份}` `{focus} 市場規模 預估` |
| 找空方觀點 | `{公司名} 風險 疑慮` `{公司名} 高估 修正` |

**先看日期再決定要不要 fetch。** 搜尋結果的 snippet 通常帶發布日期——發布日超過半年的先跳過，超過 1 年的一律不 fetch。fetch 全文是這個階段最貴的動作，只花在通過日期篩選、而且 snippet 顯示有具體數字的頁面上。

摘要有數字但被截斷時才 fetch 全文。純為了「多看一點」而 fetch 是浪費。

**日期陷阱**：查詢時帶當前年份，不要帶舊年份，否則會拿到過期結果。財經媒體常把舊文重新推播，網址日期與內容日期不一定一致，以內文標註的發布時間為準。

## 常見坑

**1. 法說會財測會過期。** 3 月講的全年展望，5 月法說會可能已經上修或下修。永遠用最新一場，並在報告中標註每個財測的發布日期。

**2. 業務別分類會變動。** 同一家公司不同季的產品分類可能不同。不要為了讓圖表好看而強行對齊，在圖表下加註說明。

**3. 「近四季 EPS」不等於「全年 EPS」。** 聚合站常混用，看清楚欄位定義。

**4. 匯損／匯兌收益會嚴重扭曲單季 EPS。** 出口比重高的公司，某季 EPS 暴跌可能是匯損而非本業衰退。看到異常季度，一定要查是不是業外因素，並在報告中說明。

**5. 媒體標題的「法人估」常常沒有出處。** 找不到是哪一家法人、什麼時候估的，就降級成 L3 或不用。

**6. 同一則新聞會被多個網站轉載。** 三個網站寫同樣的數字不等於三個獨立來源。判斷是否為同一原始出處，轉載不算交叉驗證。
